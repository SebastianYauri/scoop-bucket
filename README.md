# Scoop bucket for Clawdy

[Clawdy](https://github.com/SebastianYauri/clawdy) is a tiny pixel buddy that shows your Claude usage
and acts out what Claude Code is doing.

```powershell
scoop bucket add sebastianyauri https://github.com/SebastianYauri/scoop-bucket
scoop install clawdy
```

Update with `scoop update clawdy`. The manifest follows each new Clawdy release automatically.
